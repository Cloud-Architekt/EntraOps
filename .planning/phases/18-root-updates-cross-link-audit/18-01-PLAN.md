  <name>Task 2: Cross-link audit of docs/README.md</name>
  <files>docs/README.md</files>
  <action>
Run a programmatic audit of all markdown links in docs/README.md against the actual repo file tree using the steps below. Fix any issues found; write-back to docs/README.md only if changes are needed.

**Step 1 — Extract all linked paths from docs/README.md:**
```bash
grep -oP '\[.*?\]\(\K[^)]+(?=\))' docs/README.md | grep -v '^http' | sort
```
This gives relative paths (e.g. `concepts.md`, `user-guide/dashboard.md`, ...).

**Step 2 — Check each path resolves from the docs/ directory:**
For each relative path `P` extracted above, check that `docs/P` exists:
```bash
# Example check for each path
find docs -type f -name "*.md" | sed 's|docs/||' | sort
```
Compare the two lists. Any path in docs/README.md that has no corresponding file → BROKEN LINK (must be fixed or removed).

**Step 3 — Find orphaned .md files:**
List all .md files under docs/ (excluding README.md itself and any stubs):
```bash
find docs -name "*.md" ! -name "README.md" | sed 's|docs/||' | sort
```
Cross-reference against extracted linked paths. Any .md file NOT appearing in docs/README.md → ORPHANED (must be added as a row in the hub table or linked from the appropriate section).

**Step 4 — Apply fixes:**
- If a link target doesn't exist: Update the link to the correct path or remove the row if the file was never created.
- If a .md file is orphaned: Add it as a new row in the docs/README.md table under the appropriate section.
- If everything checks out (expected outcome based on pre-audit): No edits needed; document the clean result in the SUMMARY.

**Expected clean state (based on current repo):** All 15 linked files exist; no orphaned .md files other than README.md. Verify this is still true after phases 13–17 commits.

# Verify all linked .md paths exist:

import re, os, sys
with open('docs/README.md') as f:
