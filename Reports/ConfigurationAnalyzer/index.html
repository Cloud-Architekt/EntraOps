Configuration Analyzer

Compare EntraOps Tenant Governance snapshots over time - built entirely from the git history of TenantGovernance/Snapshots: a change timeline, a per-snapshot change list and a two-snapshot comparison with property-level diffs. See Conditional Access Analysis for the CA policy flow Sankey and coverage gap checks, EIDSCA Findings for the EIDSCA control evaluation, and Access Package Flow for the entitlement management request/approval/target Sankey.

No Configuration Analyzer dataset found. Generate data/configuration-analyzer-data.js from your repository's git history first:

Import-Module ./EntraOps -Force; New-EntraOpsTenantGovernanceConfigurationAnalyzerData

The Tenant Governance Snapshot feature must be enabled (EntraOpsConfig.json › TenantGovernanceSnapshot.EnableTenantGovernanceSnapshot) and at least one snapshot must have been captured with Save-EntraOpsTenantGovernanceSnapshotJson. Then reload this page.

Control Plane Management Plane User Access

Only resources with embedded content in the selected snapshot are scanned, and only for the specific fields documented to carry a user/group id (e.g. Administrative Unit members, Conditional Access IncludeUsers/IncludeGroups and Authentication Method policy IncludeTargets, access package requestors/approvers, role schedule request principals, group owners/members and Intune assignment targets). Exclusions are not evaluated. An id not classified by EntraOps is treated as User Access. Included group targets are resolved through their transitive membership by default; set ConfigurationAnalyzer.ResolveGroupMembersForPrivilegedAssets to false in EntraOpsConfig.json to skip that resolution.
