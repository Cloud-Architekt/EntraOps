Conditional Access Analysis

Visualize how the Conditional Access policy set of a captured Tenant Governance Snapshot is configured as a filterable Sankey flow (Assignments → Policy → Target resources → Network → Conditions → Grant controls), and review built-in Conditional Access coverage gap checks.

No Configuration Analyzer dataset found. This app reuses the same dataset as Configuration Analyzer - generate ../ConfigurationAnalyzer/data/configuration-analyzer-data.js from your repository's git history first:

Import-Module ./EntraOps -Force; New-EntraOpsTenantGovernanceConfigurationAnalyzerData

The Tenant Governance Snapshot feature must be enabled (EntraOpsConfig.json › TenantGovernanceSnapshot.EnableTenantGovernanceSnapshot) and at least one snapshot must have captured microsoft.entra.conditionalAccessPolicy resources with Save-EntraOpsTenantGovernanceSnapshotJson. Then reload this page.
