Privileged Assets

An object-centric view of every privileged user, group, service principal and application (including all object sub types) from the Privileged EAM export. It shows the relationships behind each object - owners, sponsors, owned objects and devices, identity parent, associated work account and PAW device, and administrative units - and compares the object tier with the classification of its role assignments. Role assignment details open in the side panel and link to the EAM Dashboard and Access Path Map.

Maintain the target tier of privileged objects with the classification method configured in EntraOpsConfig.json: compare the current tier of each object with its target tier and the role assignments with the highest classification, import or export the worklist as CSV or JSON, and download the Object Classification File or generate a PowerShell script that sets the tier custom security attributes, depending on the enabled classification sources. Select objects in the Overview or add them below.

PowerShell script for custom security attributes

Generates a reviewable script that sets the tier level and tier name custom security attributes (names from EntraOpsConfig.json › CustomSecurityAttributes) for users, service principals and applications in the worklist whose target tier differs from the current tier. Groups are skipped because they don't support custom security attributes - classify them with Alternate Tier Level Attributes Group filters. Nothing is executed from this page.
