Access Package Flow

Visualize Entra ID Governance entitlement management from a captured Tenant Governance Snapshot as a filterable Sankey flow - Requestor scope → Assignment policy → Access package → Target resource role - the same pattern as Conditional Access Analysis's CA Policy Flow. Every requestor, approver and target resource that resolves to a known object is enriched with its access tier (from the optional EAM Dashboard classification), to help identify access packages that grant Control Plane / Management Plane resources without approval, or whose approver is classified at a lower privilege tier than the resource being approved.

No Configuration Analyzer dataset found. This app reuses the same dataset as Configuration Analyzer - generate ../ConfigurationAnalyzer/data/configuration-analyzer-data.js from your repository's git history first:

Import-Module ./EntraOps -Force; New-EntraOpsTenantGovernanceConfigurationAnalyzerData

The Tenant Governance Snapshot feature must be enabled (EntraOpsConfig.json › TenantGovernanceSnapshot.EnableTenantGovernanceSnapshot) and at least one snapshot must have captured the microsoft.entra.entitlementManagementAccessPackage* resource types with Save-EntraOpsTenantGovernanceSnapshotJson. Then reload this page.
