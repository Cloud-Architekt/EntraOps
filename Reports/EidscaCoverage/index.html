EIDSCA Findings

Checks from Entra ID Security Config Analyzer (EIDSCA) evaluated against the properties already captured by a Tenant Governance Snapshot.

No Configuration Analyzer dataset found. This app reuses the same dataset as Configuration Analyzer - generate ../ConfigurationAnalyzer/data/configuration-analyzer-data.js from your repository's git history first:

Import-Module ./EntraOps -Force; New-EntraOpsTenantGovernanceConfigurationAnalyzerData

The Tenant Governance Snapshot feature must be enabled (EntraOpsConfig.json › TenantGovernanceSnapshot.EnableTenantGovernanceSnapshot) and at least one snapshot must have been captured with Save-EntraOpsTenantGovernanceSnapshotJson. Then reload this page.
