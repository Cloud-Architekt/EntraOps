Each tool lives in its own subfolder and stays fully functional when the subfolder is copied elsewhere. Refresh the underlying datasets with the EntraOps PowerShell module: New-EntraOpsClassificationExplorerData (Classification Explorer), New-EntraOpsPrivilegedEamDashboardData (EAM Dashboard), New-EntraOpsPrivilegedAssetsData (Privileged Assets), New-EntraOpsAccessPathMapData (Access Path Map), New-EntraOpsTierBreachAnalyzerData (Tier Breach Analyzer), New-EntraOpsPrivilegedEamPrivilegeHistoryData (Privilege History), New-EntraOpsTenantGovernanceConfigurationAnalyzerData (Configuration Analyzer, Conditional Access Analysis, EIDSCA Findings and PIM Request Flow - they share one dataset) and New-EntraOpsAccessPackageFlowData (Access Package Flow's optional "assigned" enrichment) — or all at once with New-EntraOpsReportingData.
